# LogicLab v1.0.0 · Windows x64

数字逻辑电路工作台的首个 Windows 安装版。下载下面 Assets 中的 **`LogicLab-1.0.0-Windows-x64-Setup.exe`**，按向导安装，再从开始菜单打开 LogicLab。

安装包包含已经构建的 React 前端、Python/FastAPI 运行环境、Windows 原生 C++ 仿真核心和器件库。无需另装 Python、Node.js、Visual Studio、CMake 或 WSL。

此版本提供 45 种器件、拖拽与连线编辑、工程保存、数字波形查看、撤销与重做、PNG 导出，以及启动和退出控制窗口。程序只在本机运行，工程保存在 `%LOCALAPPDATA%\LogicLab`；卸载会保留工程数据。

附带的 `安装包说明.md` 介绍安装包的含义、安装方法、数据备份、升级与卸载。`SHA256SUMS.txt` 用于检查安装包完整性，`verification.txt` 记录该构建的实际安装与运行测试，`build-dependencies.txt` 列出打包所用的 Python 依赖版本。

发布前在 Windows x64 环境实际检查了安装、前端加载、原生仿真、重复启动、工程持久化、控制窗口启动、正常退出以及卸载后的数据保留。

**当前版本未签名。** 启用 Windows 智能应用控制或强制签名策略的电脑可能直接阻止运行，需要可信发布者签名版本或组织管理员按既有政策处理。请不要关闭系统防护。

GitHub 自动提供的 `Source code (zip)` / `Source code (tar.gz)` 是开发源码；普通用户应下载上面的 `Setup.exe` 安装程序。
