# LogicLab Windows 安装包说明

## 安装包是什么

`LogicLab-1.0.0-Windows-x64-Setup.exe` 是 **LogicLab 数字逻辑电路工作台的 Windows 安装程序**。双击它，按向导安装后，就可以从开始菜单打开工作台。

它把已经构建好的程序、运行环境和资源一起安装到电脑上，创建启动快捷方式，并提供卸载入口。GitHub 的 “Download ZIP” 是源码，需要自行安装开发工具、编译和启动；这个 `Setup.exe` 是供普通用户直接安装使用的成品。

## 包内包含什么

| 内容 | 用途 |
| --- | --- |
| `LogicLab.exe` 启动程序 | 显示启动控制窗口，打开浏览器工作台，退出时停止服务 |
| 已构建的 React 前端 | 电路编辑、器件面板、工程管理、仿真和波形界面 |
| FastAPI 服务和 Python 运行环境 | 提供本机工程管理与仿真接口 |
| Windows 原生 `logic_sim.pyd` 和所需动态库 | 执行 C++ 数字逻辑仿真 |
| 器件库 JSON | 逻辑门、触发器、芯片和输入输出器件的定义 |
| 本说明文档 | 说明安装、运行、数据保存和卸载方式 |

安装包不会包含开发机的工程数据库、日志、虚拟环境或 `node_modules`。安装好的运行环境不需要用户另外安装 Python、Node.js、Visual Studio、CMake 或 WSL。

## 系统要求与安装

- Windows 10 / 11，x64 电脑。当前未针对 Windows ARM64 或 32 位系统验证。
- 一个现代浏览器，例如 Edge、Chrome 或 Firefox。
- 使用当前用户安装，默认无需管理员权限。

1. 双击 `LogicLab-1.0.0-Windows-x64-Setup.exe`。
2. 按安装向导选择目录；默认是 `%LOCALAPPDATA%\Programs\LogicLab`。
3. 如需要，勾选创建桌面快捷方式。
4. 完成后，从开始菜单启动 **LogicLab**。

本构建未购买代码签名证书，因此安装程序没有发布者数字签名。若 Windows 显示未知发布者提示，应核对文件来源和配套 SHA-256 校验值；不要关闭系统防护。

## 启动和退出

启动后会显示一个控制窗口，并自动在默认浏览器中打开工作台。点击“打开工作台”可以再次打开页面，点击“退出并停止服务”或关闭控制窗口可以退出程序。退出前请保存工程；关闭浏览器标签页本身不会停止服务。

程序只监听本机 `127.0.0.1`，启动时自动选择空闲端口，地址形如 `http://127.0.0.1:49152`。每次启动的端口可能不同，请使用快捷方式或控制窗口打开，避免收藏固定端口。重复启动会复用当前用户数据目录对应的服务。

安装和日常仿真无需联网。该版本使用“本机服务 + 浏览器界面”的方式运行；不是独立浏览器引擎窗口，也不是部署在互联网上的网站。

## 工程数据在哪里

用户数据保存在 `%LOCALAPPDATA%\LogicLab`，与程序安装目录分开：

- `projects.db`：工程数据库。
- `desktop.log`：启动与服务日志，用于排查问题。
- `runtime.json` / `runtime.lock`：运行状态文件，不是工程备份。

备份时先退出 LogicLab，再复制 `projects.db`；也可以在界面中导出电路 JSON。恢复数据库时同样先退出，再替换文件。浏览器本地保存的偏好或未保存内容不会随数据库备份，请先保存或导出工程。

## 升级和卸载

升级前先退出程序，再运行新版本安装包，安装到原目录。开始菜单的卸载快捷方式或 Windows“设置 → 应用 → 已安装的应用”可以卸载。

卸载会删除程序和快捷方式，**保留 `%LOCALAPPDATA%\LogicLab` 内的工程与日志**。需要彻底清除数据时，请先确认工程已有备份，再手动删除这个目录。

## 发布文件与校验

构建产物位于仓库的 `dist/installers/`：

| 文件 | 含义 |
| --- | --- |
| `LogicLab-1.0.0-Windows-x64-Setup.exe` | 实际安装程序，可以发给其他 Windows 用户 |
| `安装包说明.md` | 本说明，可单独阅读，也随程序安装 |
| `SHA256SUMS.txt` | 安装包的 SHA-256 摘要，用于检查文件是否完整 |
| `build-dependencies.txt` | 生成该安装包时使用的 Python 依赖版本 |

PowerShell 中执行 `Get-FileHash .\LogicLab-1.0.0-Windows-x64-Setup.exe -Algorithm SHA256`，其 Hash 应与 `SHA256SUMS.txt` 一致。摘要只能检查一致性，不替代可信的下载来源或数字签名。

## 开发者如何重新构建

在 Windows 本地磁盘检出源码，准备原生 x64 CPython 3.12、Node.js 24、CMake 3.21+、Visual Studio 2022 的 C++ 工具和 Inno Setup 6。

```powershell
.\scripts\package-windows.ps1 -Python C:\path\to\python.exe
.\scripts\test-installer.ps1 -Installer .\dist\installers\LogicLab-1.0.0-Windows-x64-Setup.exe
```

若 Inno Setup 未加入 PATH，可传入 `-InnoSetup 'C:\tools\Inno Setup 6\ISCC.exe'`。脚本先构建原生仿真核心和前端，再用 PyInstaller 收集运行环境，最后由 Inno Setup 生成安装程序。版本号由 `backend/app/runtime.py`、`packaging/installer.iss` 和构建脚本统一维护。

GitHub Actions 的 `Windows Installer` 工作流在 Windows 2022 环境完成构建，实际安装到隔离临时目录，检查前端、原生仿真、工程保存、重复启动、控制窗口启动和卸载后数据保留。通过后将安装包、说明和校验文件上传为 `LogicLab-Windows-x64-installer` 构建产物；不会自动创建 GitHub Release。

打包方式参考：[PyInstaller 的运行环境打包说明](https://pyinstaller.org/en/stable/operating-mode.html)、[Inno Setup 官方资料](https://jrsoftware.org/isinfo.php)。
